# Публикатор «Давай узнаем» для Инстаграма

Бесплатная система: Claude раз в неделю готовит посты и кладёт их сюда, а GitHub каждый час проверяет очередь и публикует то, чему пришло время, через официальный Instagram API.

## Как устроены папки

| Папка | Что там |
|---|---|
| `posts/drafts/` | черновики от Claude. Сами не публикуются |
| `posts/queue/` | одобренные посты. Публикуются в назначенное время |
| `posts/published/` | опубликованные посты со ссылкой на пост |
| `posts/failed/` | посты, которые не вышли, с причиной в `result.json` |

Один пост — одна папка, например `posts/queue/2026-11-24-schet-do-10/`:

```
post.json   — время и подпись
1.jpg       — картинки по порядку (до 10 для карусели, 1 для сторис)
2.jpg
```

```json
{
  "publish_at": "2026-11-24T10:00:00+03:00",
  "type": "feed",
  "caption": "Подпись к посту\n\n#давайузнаем #занятиясдетьми"
}
```

`type`: `feed` — пост или карусель, `story` — сторис. Картинки только JPG, лучше 1080×1350.

Чтобы одобрить черновик, достаточно сказать Claude «ок» в чате: он перенесёт папку из `drafts` в `queue`.

## Настройка (один раз, около 40 минут)

### Шаг 1. Профессиональный аккаунт в Инстаграме

Инстаграм → Профиль → ☰ → Тип аккаунта и инструменты → «Переключиться на профессиональный аккаунт» → «Автор» или «Бизнес». Это бесплатно.

### Шаг 2. Ключ доступа от Meta

Сайт Meta в России открывается только через VPN.

1. developers.facebook.com → «Мои приложения» → «Создать приложение».
2. Сценарий: **«Управление сообщениями и контентом в Instagram»**. Название — например `Davay Publisher`.
3. Слева: **«API setup with Unified login»**. Meta попросит **бизнес-портфолио** — создайте бесплатно: название «Давай узнаем», ваши имя и почта.
4. В блоке «1. Настройте приложение» нажмите **«Создать новую конфигурацию»**:
   - объект компании — **аккаунт Инстаграма «Давай узнаем»** (обязательно); рекламный аккаунт не нужен;
   - разрешения оставьте как предлагает Meta (нужны `instagram_basic` и `instagram_content_publish`).
5. Создайте **маркер доступа системного пользователя**: Meta покажет кнопку на этой же странице или отправит в «Настройки компании → Пользователи системы». Срок действия — **«Никогда»**.
6. Скопируйте длинную строку — это ключ. Никому, кроме GitHub, его не пересылайте.

Такой ключ бессрочный, продлевать его не нужно.

Если экран выглядит иначе — пришлите Claude скриншот.

### Шаг 3. Репозиторий на GitHub

1. Зарегистрируйтесь на github.com.
2. «New repository» → название `davay-instagram` → **Public** (иначе Инстаграм не сможет скачать картинки; всё равно там будут только посты, которые и так выйдут публично) → Create.
3. Загрузите в него содержимое этой папки: «uploading an existing file» → перетащите все файлы и папки, включая скрытую `.github`.
   Если `.github` не перетаскивается — создайте файлы через «Add file → Create new file» с именем `.github/workflows/publish.yml` и вставьте текст из архива; так же для `refresh-token.yml`.

### Шаг 4. Секрет

В репозитории: Settings → Secrets and variables → Actions → New repository secret.

- Name: **`IG_TOKEN`**, Secret: ключ из шага 2 → Add secret.

Больше ничего не нужно: номер аккаунта Инстаграма программа найдёт сама. Если проверка скажет, что не нашла аккаунт, добавьте второй секрет `IG_USER_ID` — номер подскажет Claude.

### Шаг 5. Проверка

Вкладка Actions → «Публикация в Инстаграм» → Run workflow → режим `check` → Run.
Через минуту в журнале должно быть: «Ключ работает. Аккаунт: @…».

### Шаг 6. Подключить к Claude

Подключите GitHub к Claude (в настройках, раздел подключений GitHub) и напишите в чат название репозитория. Claude заведёт еженедельную задачу и пришлёт первые черновики.

## Что важно знать

- **Время.** GitHub проверяет очередь раз в час, иногда с задержкой до 15–30 минут. Пост на 10:00 выйдет между 10:07 и примерно 10:40.
- **Если пост не вышел** — он в `posts/failed/`, причина в `result.json`. При временных сбоях публикатор сам пробует ещё 2 раза, раз в час.
- **Сторис** выходят без музыки, опросов и наклеек: API этого не умеет. Такие сторис выкладывайте вручную.
- **Ключ** бессрочный. Если вы удалите приложение или системного пользователя в Meta, ключ перестанет работать — тогда создайте новый (шаг 2) и замените секрет `IG_TOKEN`.
- **Пауза.** GitHub отключает расписание, если в репозитории 60 дней ничего не меняется. Еженедельные посты от Claude это предотвращают. После долгого перерыва зайдите в Actions и нажмите «Enable workflow».
- **Остановить всё:** Actions → «Публикация в Инстаграм» → ⋯ → Disable workflow.
- **Закон.** Посты — бесплатные материалы без цен и призывов купить. В шапке профиля — ссылка на страницу с бесплатными материалами, а не на магазин.
