# Листы для бесплатных постов

Сюда кладутся ваши листы для постов «бесплатный материал»: JPG, PNG или PDF.
Название файла — по-русски или латиницей, как удобно, например `счёт-до-10-лист1.jpg`.

Загрузить: на этой странице «Add file» → «Upload files» → перетащите файлы → «Commit changes».
Или просто пришлите их Claude в чат.
